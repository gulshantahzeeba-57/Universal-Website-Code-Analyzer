What it checks

One scan, four disciplines

ScanForge doesn't just lint your code or ping your homepage — it reasons about the project the way a reviewer covering SEO, performance, security and code quality together would.

◎

Live URL scans

Paste any public URL. ScanForge fetches the live page, reads its markup and content, and grades it in place.

▦

Codebase audits

Upload a project as a .zip. Structure, tech stack, styling and scripts get reviewed without you setting up anything locally.

▲

Risk-ranked findings

Every result lands in Passed, Warning or Critical — so you fix what actually matters before what's merely cosmetic.

↺

Scan history

Every audit is logged with its score and timestamp, so you can track whether a site or repo is actually improving.

The process

From link to fix list in three steps

01

Point it at something

A live URL or a .zip export of your project — ScanForge accepts either as the starting point.

02

It reads before it scores

Markup, content, file structure and stack are parsed first, then evaluated against SEO, performance, security and quality checks.

03

Get a ranked report

Passed checks, warnings and critical risks, sorted by what would hurt users or rankings the most.
